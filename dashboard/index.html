How implied value is computed

One function scores every protocol, from the snapshot's own figures. No protocol name is special-cased, and no row is hand-picked.

Implied value is this entry's own claim, never make.fun's. A protocol "records no token" when DefiLlama's record carries no token for it — that is the record, not proof it has none.
